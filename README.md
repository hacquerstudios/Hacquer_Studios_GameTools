# Hacquer Studios GameTools

A collection of small tools and utilities to support game development workflows. Projects in this repository target .NET 10 and are intended to be opened in Visual Studio or built with the dotnet CLI.

## Prerequisites

- .NET 10 SDK
- Visual Studio 2022/2026 or another IDE that supports .NET 10
- Git
## Usage

for useage see https://github.com/hacquerstudios/Hacquer_Studios_GameTools/blob/develop/Hacquer_Studios_GameTools/PACKAGE_README.md
## Quick start

```powershell
git clone https://github.com/hacquerstudios/Hacquer_Studios_GameTools.git
cd Hacquer_Studios_GameTools
# open the .sln in Visual Studio or build from CLI
dotnet restore
dotnet build --configuration Release
```

## Running

Each project/tool has its own entry point. In Visual Studio set the desired project as startup or run from the project folder:

```powershell
cd Path/To/Project
dotnet run
```
